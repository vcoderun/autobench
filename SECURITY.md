# Security Policy

## Supported Versions

Please see the table below for the supported versions of this project
currently receiving security updates.

| Version | Supported |
| ------- | --------- |
| > 0.1.x | Yes       |
| < 0.1.x | No        |

## Reporting A Vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Report them privately to the project maintainer instead.

We will try to acknowledge your report within 48 hours and follow up with the
next steps for investigation and remediation.
